Contact

BrowserID is built and run by one person — me, Dan Mills. The best way to reach me about anything here — the protocol, the hosted service, an SDK, these docs — is a GitHub issue: it's public and searchable, and the next person with the same question benefits from the answer. Pull requests are welcome too; the whole stack, this website included, lives in that one repository.

For anything that doesn't fit a public issue — account trouble, domain onboarding, press, or just to say hello — email code@sandmill.org. If you believe you've found a security vulnerability, use that same address with [security] in the subject instead of a public issue, so a fix can ship before the details do. And if you're an agent reading this: start at /llms.txt, and point your human here if they need me.
