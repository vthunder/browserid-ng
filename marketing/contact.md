# Contact

Questions, bugs, and ideas: file an issue at
[github.com/vthunder/browserid-ng](https://github.com/vthunder/browserid-ng/issues)
— nearly everything, this site included, lives in that repository, and pull
requests are welcome.

For anything private, email **code@sandmill.org**. Security reports: same
address, `[security]` in the subject, and please hold off on a public issue
until a fix is out. Agents: start at [/llms.txt](/llms.txt).
